## Stylus Nexus

We build and govern workflows for AI-assisted work. Control gates,
lifecycle loops, evaluation harnesses, and explicit decisions about
where a human stays in the loop.

**Products**
- [CritForge](https://www.getcritforge.com) — a semantic consistency
  engine over a knowledge graph. 21 interlinked generators sharing a
  memory model, with contradiction detection across generated entities.
  Licensing compliance, user content ownership, metered per-request AI
  cost model. Commercial.
- [Soundstellation](https://trees.soundstellation.com) — a
  provenance-first graph. Every relationship is source-backed, curated
  paths are explicitly bounded, and the evidence and its limits stay
  visible rather than hidden behind a confidence score.

**Open source**
- [agent-armor](https://github.com/stylusnexus/agent-armor) — AI agent
  security framework implementing the DeepMind Agent Traps taxonomy.
  Pre-execution action gate, audit logging with compliance evidence
  packages. MIT.
- [skill-loop](https://github.com/stylusnexus/skill-loop) — a model
  lifecycle governance loop for agent skills: observe, inspect, amend,
  evaluate on branch, merge or roll back.
